# Python Master (Roman Urdu) 🐍

Python Master aik interactive Streamlit learning application hai jo Roman Urdu mein Python aur AI/ML Basics seekhne ke liye banayi gayi hai.

## Features
- **4 Levels:** 🌱 Beginner, 🚀 Intermediate, 🔥 Advanced, aur 🤖 AI/ML Basics.
- **50 Interactive Topics:** Har topic ke saath theory, code examples, interactive runner (jahan aap apna custom Python code run kar sakte hain), aur quiz shamil hain.
- **Interactive Terminal:** Code run kar ke live output dekhein.
- **Cheat Sheet & Projects:** Quick revision cheat sheet aur hands-on projects list.

## Installation

Aap is app ko as a package local build kar ke install kar sakte hain:

1. Apne terminal mein project directory par jayein:
   ```bash
   cd python-master
   ```

2. Package ko local develop mode mein install karein:
   ```bash
   pip install -e .
   ```

## Usage

Installation ke baad, aap pure system par kahin se bhi simple is command se application launch kar sakte hain:

```bash
python-master
```

Ye command automatically Streamlit dashboard ko launch kar degi aur aap browser mein study kar sakenge!
